# Contributing

1. Keep all examples synthetic; do not submit real student data, SIS exports, credentials, or personal information.
2. Keep the prototype dependency-free unless a clear reason and setup instructions are added.
3. Describe data assumptions and edge cases in the README or `docs/`.
4. Run the manual checks in [`docs/TEST_PLAN.md`](docs/TEST_PLAN.md) after changing the app.
5. Do not label demonstration course data as official without verifying the relevant approved syllabus and admission batch.
