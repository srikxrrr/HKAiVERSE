A production SIS integration would require institutional permission, authentication, access controls, privacy review and approved APIs; none is implemented here.

Run locally or publish with GitHub Pages

This prototype is a static website with no build step, external libraries, server, or API keys.

  1. Save the main page as index.html in your project folder.
  2. Open index.html in a browser to run it locally.
  3. Upload index.html and the project documentation to a GitHub repository.
  4. In GitHub, open Settings → Pages, select deployment from the main branch and /(root), then save.

Publish only the synthetic demonstration data. Never commit real student records, SIS credentials, tokens, or other private institutional information.
